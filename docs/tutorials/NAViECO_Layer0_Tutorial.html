Hierarchical cell-type annotation

01 Before you start

Install NAViECO into your Python environment, then use a single-cell RNA-seq .h5ad containing raw, non-negative RNA counts. Counts may be stored in adata.layers["counts"] (preferred) or adata.X. Cell and gene IDs must be unique.

terminal
python -m pip install "git+https://github.com/LuckyRaphael/NAViECO.git"

If using multiple samples, specify the exact column in adata.obs that contains sample IDs (for example, "sample" or "orig.ident"). All cells from one sample should share an ID, and distinct samples should have distinct IDs.

Before running: Replace query_scRNA.h5ad with your file and batch_key="sample" with your actual metadata column. Set batch_key=None only when appropriate; NAViECO then uses Dataset, if available, or treats the query as one domain. Run sizable datasets on a compute node.

02 Annotate cell types

This is the main Layer 0 command. NAViECO uses the published NAViECO_v1 reference and trains hierarchical CONCORD classifiers from reference-labelled seed cells; query cells are not used as labelled training examples. The reference is automatically downloaded and checksum-verified on first use.

python
from pathlib import Path
import navieco as nv

Path("results").mkdir(exist_ok=True)

nv.annotate(
    data="query_scRNA.h5ad",
    reference="NAViECO_v1",
    level="fine",
    batch_key="sample",
    device="auto",
    run_umap=True,
    output="results/query_NAViECO_Layer0.h5ad",
)

level="fine" runs all three annotation levels. Use level="coarse" for Levels 1–2 only. Re-running nv.annotate() starts annotation/training again; use the saved H5AD for routine review.

StagePredictionFineCoarse
Level 1Five broad reference lineages✓✓
Level 2Cell types within predicted Level 1 lineages✓✓
Level 3Finer cell types within predicted Level 2 parents✓—

The full NAViECO_v1 label vocabulary comprises 5 / 23 / 129 classes at Levels 1 / 2 / 3, respectively. Any given dataset may contain fewer observed classes.

03 Inspect your annotations

Read the saved H5AD to inspect predicted cell types. In fine mode, three levels of annotations and their confidence columns are appended to .obs. The original query data and metadata are retained.

python
import anndata as ad

adata = ad.read_h5ad("results/query_NAViECO_Layer0.h5ad", backed="r")
adata.obs[["navieco_level1", "navieco_level2", "navieco_level3"]].head()
adata.file.close()
Interpretation: navieco_level*_confidence values are hierarchical prediction scores, not calibrated probabilities that a label is biologically correct. Training/validation accuracy is evaluated on held-out reference cells, not on unlabelled query ground truth.

04 Saved files

With output set, NAViECO writes the annotated H5AD and companion reports alongside it, using the output filename as their prefix.

OutputPurpose
query_NAViECO_Layer0.h5adAnnotated cells, metadata, hierarchy labels and available embeddings
…_UMAP.pdfGlobal Query UMAP coloured by annotation levels
…_branch_UMAP.pdfBranch-specific projections for Level 2/3 (independent coordinate spaces)
…_annotation.pdfCell-type abundance and confidence summaries
…_training.pdfStage-wise training and held-out reference validation curves
…_training_summary.csvModel-level training metrics
…_training_metrics.json, …_run_config.jsonTraining histories and configuration

Annotation / UMAP PDFs depend on run_umap=True. The separate branch UMAPs are not aligned and should not be compared using their absolute coordinates.
