01 Input requirements

Start from a completed NAViECO Layer 0 H5AD. It must include adata.obs["navieco_level2"] and original raw RNA counts in adata.X. Having raw counts only in adata.layers["counts"] is not sufficient if .X has already been normalized.

Layer 1 uses the NAViECO_states_v1 reference. It aligns query genes, holds the reference state signatures (W) fixed and estimates query-specific state contributions (H); this is not de novo state discovery.

Important: An input with normalized/log-transformed .X should not be used for Layer 1 recovery. Keep a copy of the original raw counts in .X before running this step. The input file is not modified.

02 Recover cell states

Set the input path to your Layer 0 result and choose a new output filename. Missing output folders are created by the API. The reference is retrieved and verified automatically on first use.

python
from pathlib import Path
import navieco as nv

Path("results").mkdir(exist_ok=True)

adata = nv.recover_states(
    data="results/query_NAViECO_Layer0.h5ad",
    reference="NAViECO_states_v1",
    output="results/query_NAViECO_Layer1.h5ad",
)
adata.file.close()

nv.recover_states() estimates state contributions within mapped cell-type parents. The original H5AD remains unchanged, and the new file contains the recovered state assignments and diagnostics.

03 Interpret the result

The recovered state is stored in navieco_state; its associated NMF parent is navieco_state_parent. The field navieco_state_status distinguishes successfully recovered cells from those outside the reference mapping or without a valid assignment.

python
import anndata as ad

adata = ad.read_h5ad("results/query_NAViECO_Layer1.h5ad", backed="r")
adata.obs[["navieco_state_parent", "navieco_state", "navieco_state_status"]].head()
adata.file.close()

The other added diagnostics are navieco_state_top1, navieco_state_margin and navieco_state_retained_mass. These reflect the state-assignment process; they are not calibrated probabilities of biological correctness.

04 Generate state-marker heatmaps

Once state recovery is complete, one command exports the compact heatmaps and marker tables. This step reads the saved Layer 1 H5AD; it does not fit H again.

python
nv.pl.state_heatmaps(
    "results/query_NAViECO_Layer1.h5ad",
    output_dir="results/state_heatmaps",
)

Marker selection. For each state, up to five measurable, variable reference genes are ranked by state-versus-rest log2FC within the same cellular parent. Eligible genes require log2FC > 0.05 and specificity_delta > 0 (a higher log2FC than the other states). Displayed gene-wise expression z-scores are clipped to [−1, +1].

Heatmap genes and marker statistics are descriptive, query-dependent summaries of the reference gene set. They are not independent differential-expression validation or clinically validated biomarkers.

06 Saved files

Each eligible recovered parent receives a PDF and a high-resolution PNG. Three CSV files provide selected marker genes, full reference-gene comparisons and QC data.

File pattern in <code>results/state_heatmaps/</code>Contents
query_NAViECO_Layer1_<parent>_SE_style_compact_heatmap.pdfVector figure for an eligible parent
query_NAViECO_Layer1_<parent>_SE_style_compact_heatmap.png600-dpi raster figure
query_NAViECO_Layer1_SE_style_top5_markers.csvUp to five selected markers per state
query_NAViECO_Layer1_reference_gene_state_vs_rest.csvFull state-versus-rest reference-gene comparisons
query_NAViECO_Layer1_state_heatmap_qc.csvParent-wise coverage and QC summary

The number of plots depends on the recovered parents and their state assignments. The H5AD itself is written to results/query_NAViECO_Layer1.h5ad, independent of the heatmap directory.
