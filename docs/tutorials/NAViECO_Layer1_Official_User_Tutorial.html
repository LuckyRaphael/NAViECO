NAViECO · Layer 1¶

Official user tutorial | Reference-based cell-state recovery and compact heatmaps¶

Code version: NAViECO GitHub a7d30e3 · Reference: NAViECO_states_v1 · Python: 3.11 recommended.

This tutorial runs fixed-reference transcriptional state recovery on an existing Layer 0-annotated .h5ad file and generates compact state-marker heatmaps for every eligible parent. The workflow uses two public commands: nv.recover_states(...) and nv.pl.state_heatmaps(...). No manual marker selection or plot configuration is needed.

Input: completed NAViECO Layer 0 .h5ad, with adata.obs["navieco_level2"] and original raw RNA counts in .X. Anndata .layers["counts"] alone is not sufficient if .X has been normalized.

Outputs: a new Layer 1 .h5ad with six state-assignment columns, plus per-parent PDF/PNG heatmaps and three CSV reports (Top 5 markers, all reference-gene state comparisons, and QC). The original input is unchanged.

For large datasets, run on a compute node. The file-to-file recovery and plotting APIs process the expression matrix in chunks. The NAViECO_states_v1 reference is fetched and verified automatically on first use, or can be provided as a local extracted directory.

1 · Configure input and output paths¶

Edit the three paths below. INPUT_H5AD is the existing Layer 0 result; OUTPUT_H5AD is the exact path and filename for the new Layer 1 H5AD; HEATMAP_DIR is the independent destination folder for all PDF, PNG and CSV outputs. Both output locations can be anywhere you have write permission—they do not need to be next to the input. NAViECO creates the missing output folders automatically.

2 · Check your Layer 0 input¶

This lightweight check opens the H5AD in read-only backed mode without loading the complete expression matrix. Ensure .X contains raw non-negative integer counts, and that gene and cell IDs are unique. The reference recovery uses navieco_level2 to map cells into NMF parents; it does not use the fine navieco_level3 labels as states.

In [2]:
query = ad.read_h5ad(INPUT_H5AD, backed="r")

    print(f"Input: {query.n_obs:,} cells × {query.n_vars:,} genes")

3 · Recover reference-defined cell states¶

NAViECO aligns genes and estimates Query-specific H with fixed reference W (no retraining). It saves the Layer 1 H5AD to your chosen OUTPUT_H5AD, creating its parent folder if needed. If that file already exists, this tutorial skips recovery; change its path or deliberately remove the old result only when rerunning is intended.

In [3]:
if OUTPUT_H5AD.is_file():
    print("Using existing Layer 1 result (recovery skipped):", OUTPUT_H5AD)
else:
    OUTPUT_H5AD.parent.mkdir(parents=True, exist_ok=True)
    recovered = nv.recover_states(
        data=str(INPUT_H5AD), reference=REFERENCE, output=str(OUTPUT_H5AD)
    )
    if recovered.file is not None:
        recovered.file.close()  # Close the read-only backed output
    print("Saved Layer 1 result:", OUTPUT_H5AD)

4 · Inspect recovered states¶

navieco_state stores the assigned QC-retained state (for example NK_S01), while navieco_state_parent identifies its NMF parent. navieco_state_status distinguishes recovered cells from cells without a matching parent or without a valid assignment. top1, margin and retained_mass are assignment diagnostics, not calibrated biological probabilities.

result = ad.read_h5ad(OUTPUT_H5AD, backed="r")
try:
    required = {"navieco_state_parent", "navieco_state", "navieco_state_status"}
    if not required.issubset(result.obs.columns):
        raise KeyError(f"Missing Layer 1 columns: {sorted(required - set(result.obs.columns))}")
    display(result.obs["navieco_state_status"].value_counts(dropna=False).to_frame("cells"))
    assigned = result.obs.loc[result.obs["navieco_state_status"].eq("Recovered")]
    counts = (assigned.groupby(["navieco_state_parent", "navieco_state"], observed=True)
              .size().rename("cells").reset_index())
    display(counts.head(12))
finally:
    result.file.close()

5 · Generate all compact state-marker heatmaps (one line)¶

The plotting API reads the completed Layer 1 H5AD and saves all parent PDFs, 600-dpi PNGs and three CSV reports to your chosen HEATMAP_DIR via output_dir=HEATMAP_DIR. It does not repeat state recovery. Top 5 markers are selected from measurable fixed-W reference genes using log2FC > 0.05, specificity_delta > 0 and descending log2FC; expression heatmaps show gene-wise z-scores clipped to [-1, +1]. These marker statistics are descriptive, not independent differential-expression tests.

In [5]:
# Save plots and tables to the independent folder configured in Step 1.
HEATMAP_DIR = nv.pl.state_heatmaps(
    OUTPUT_H5AD, output_dir=HEATMAP_DIR, reference=REFERENCE, show=False
)
print("Heatmaps and reports saved to:", HEATMAP_DIR.resolve())

6 · Review the saved outputs¶

The destination is exactly HEATMAP_DIR from Step 1, not necessarily the directory containing your H5AD. Each eligible parent receives a PDF and PNG; the three CSV files contain Top 5 markers, complete reference-gene state-vs-rest comparisons, and parent-level QC. Parent coverage depends on recovered state assignments.

Notes for interpretation¶

  • Layer 0 labels vs Layer 1 states: navieco_level2 denotes annotated cell types; navieco_state denotes fixed-reference transcriptional states within mapped NMF parents.
  • W is fixed: Layer 1 estimates H in the Query; state assignments may depend on Query composition and data quality.
  • Heatmap markers are descriptive: plotted genes and Top 5 markers are limited to measurable/variable reference genes, not the whole transcriptome; they are not independently validated biomarkers.
  • Output paths are independent: OUTPUT_H5AD controls the recovered AnnData file, while HEATMAP_DIR controls all figures and CSVs; neither is required to be beside INPUT_H5AD.
  • Safe reuse: rerun the inspection and plotting steps to review saved results. Recompute recovery only when you intentionally choose a new output or remove the old result.
